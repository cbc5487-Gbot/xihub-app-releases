# Xi Hub Android 更新

[下載最新版 XiHub.apk](https://github.com/cbc5487-Gbot/xihub-app-releases/releases/latest/download/XiHub.apk)

第一次下載並覆蓋安裝 0.2.3 或更新版本，不要先解除安裝。之後在 App「連線 → App 更新 → 檢查更新」即可下載最新版，再依 Android 畫面確認安裝。也可開啟每天首次啟動時檢查更新。

更新下載可使用 Wi-Fi 或行動網路，不需要電腦開機。傳入影片與預覽仍需連到已配對的私人 Windows Hub。更新保留配對及紀錄。

Android 首次可能要求允許 Xi Hub 安裝應用程式；允許後回到「連線 → App 更新」按「安裝已下載的更新」。影片傳送中會延後安裝。

套件名稱：org.xixili.hub，Android 8.0 以上。此 App 與舊版各頻道 App 不同，不能互相覆蓋。
